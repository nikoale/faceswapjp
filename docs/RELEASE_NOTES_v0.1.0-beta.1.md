## faceswapjp v0.1.0-beta.1（ベータ版）

映像制作向けの、ローカルで完結するフェイススワップツールです。本人の同意を得た顔だけを対象にしています。

### はじめかた（Mac・ターミナル不要）
1. 下の **Source code (zip)** をダウンロードして展開します。
2. `macos/1_セットアップ.command` をダブルクリックします（初回のみ）。「開発元を確認できません」と出たら、右クリック →「開く」を選んでください。
3. ホームフォルダの「アプリケーション」にできる **faceswapjp** を起動します。

### 主な機能
- 静止画・動画の顔の差し替え（fps、タイムコード、音声、色の情報を元素材のまま保持）
- クリックで置き換える人を選択し、動画全体で自動追跡
- 手・髪を前に残すマスク、色合わせ、顔の補正
- H.264 / H.265 / ProRes / DNxHR での書き出しと、合成用マスクの出力
- 動画編集ソフト風の画面（比較スライダー、書き出し中のライブ表示、タイムライン）
- 速度チェック、まとめて処理

### 安全機能
顔の登録時の確認、同意の記録（書き換えを検知）、NSFW 判定、「AI face-swapped」の記録、ローカル処理。

### 注意
- **ベータ版です。** Mac の実機では、まだ検証していません。不具合は Issues で報告してください。速度チェックの結果を添えてもらえると助かります。
- 既定の AI モデルは**非商用ライセンス**です。
- 本人の同意がない人の顔、性的な内容、なりすましには使わないでください。詳しくは README の「使ってよいこと・いけないこと」を見てください。

詳しい変更内容は [CHANGELOG.md](https://github.com/nikoale/faceswapjp/blob/v0.1.0-beta.1/CHANGELOG.md) にあります。
